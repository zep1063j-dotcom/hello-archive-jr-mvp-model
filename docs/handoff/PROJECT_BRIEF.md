# PROJECT BRIEF

## 목표
사진으로 남기기 어려운 아이의 말·생각·감정·일상을, 부모가 매주 질문 하나에 텍스트로 답하며 기록하고 안전하게 시간순으로 보관한다. 장기적으로 아이가 성인이 되었을 때 성장 이야기를 책으로 선물하는 것이 비전이다.

## 사용자
- 핵심 고객: 어린 자녀를 키우는 부모.
- 운영자: 1인 창업자. 개발을 학습하면서 직접 코딩과 AI 기반 개발을 병행한다.

## 지금 검증하려는 것 (확인된 사실이 아니라 가설)
- 바쁜 일상에서도 부모가 매주 질문에 답해 기록하는가? (관심이 아니라 **행동**)
- 기록이 쌓인 결과물(1개월/3개월/1년)에 가치를 느끼는가? 이후 지불 의향은? (별도 검증)
- 방법: 부모 약 5명 베타 + 인터뷰. 성공 기준은 SESSION 09에서 사용자와 함께 정한다. 5명의 결과만으로 시장 수요가 입증됐다고 단정하지 않는다.

## MVP 핵심 기능
| 영역 | 내용 |
|---|---|
| A. 부모 계정 | 이메일 패스워드리스 로그인, 세션 유지, 로그아웃, 보호 페이지 접근 차단, 안전한 인증 리다이렉트 |
| B. 자녀 프로필 | 이름/별명, 생년월일, 등록·조회·수정. UI는 한 명 중심, 데이터 모델은 확장 가능 |
| C. 주간 질문 | 매주 하나, 주차-질문 일관 관리, 이번 주 질문 화면, 작성 여부 확인. 관리자 화면 없이 시드로 관리 |
| D. 텍스트 기록 | 작성·저장·조회·수정·삭제, 작성/수정 날짜, 저장 상태 표시, 중복 제출 방지 |
| E. 성장 아카이브 | 타임라인(명확한 시간순), 빈 상태, 상세 조회, 1개월 미니챕터 / 3개월 이야기집 / 1년 기록집(조회용 묶음, 책 생성 시스템 없음) |
| F. 주간 이메일 | 주 1회 질문 안내, 수신 동의, 중복 발송 방지, 발송 이력, 실패·재시도, 한국 시간. 링크 → 이번 주 작성 화면 |
| G. 개인정보 | RLS, 서버 소유권 검증, 비밀키 보호, 불필요한 개인정보 미수집, 분석 이벤트에 본문·자녀 정보 미전송, 삭제 요구 대응 구조 |

### 이메일 링크 인증 원칙
1. 유효 세션이 있으면 작성 화면으로 바로 이동.
2. 없으면 패스워드리스 인증 후 원래 요청한 작성 화면으로 이동.
3. 인증용 링크/토큰은 짧은 유효기간 + 일회성.
4. 만료된 링크는 재발급 가능.
5. 장기 유효 로그인 토큰을 일반 안내 링크에 넣지 않는다.
6. 며칠 뒤 메일을 열어도 안전하게 로그인 후 해당 화면으로 이동.
7. **주간 안내 링크(로그인 정보 없음)와 인증 링크(일회용)의 역할을 분리**한다.

## MVP 제외 (명시적 지시 전 구현 금지)
음성 녹음 · AI 글쓰기/요약 · 사진·영상 · PDF · 실물 책 · 결제/구독 · 공동 작성 · 가족 초대/복잡한 권한 · 관리자 대시보드 · 다국어 · 네이티브 앱.

## 디자인 원칙
모바일 퍼스트(375~390px 우선), 데스크톱까지 반응형. 기록 작성 행동이 가장 잘 보이게. 충분한 여백과 가독성. 로딩/저장 중/오류/빈 상태 UI. 접근성 있는 폼. 브랜드 색은 블랙+레드이나 앱 화면은 차분하고 따뜻하게(공격적·차가운 디자인 지양).
